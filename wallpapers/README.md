# Hintergrundbilder

Alle Bilder in diesem Ordner landen beim Bauen in CleanHome und sind unter **Anpassen → Hintergrund** wählbar.

**Eigene Bilder:** einfach JPG oder PNG hier hineinlegen (am besten 1920 × 1080, höchstens 3 MB), dann:

    node tools/cleanhome.js install

Bildnachweis für eigene Bilder (optional) in `captions.json` eintragen: `"dateiname.jpg": "Titel · Urheber, Lizenz"`.
